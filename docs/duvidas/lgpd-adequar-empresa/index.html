Início / Dúvidas frequentes

Minha empresa precisa se adequar à LGPD?

Na grande maioria dos casos, sim. A LGPD se aplica a qualquer pessoa ou empresa que trate dados pessoais, independentemente do porte ou do setor.

O que são dados pessoais

É qualquer informação que identifique ou possa identificar uma pessoa: nome, CPF, e-mail, telefone, endereço, foto, dados de saúde, dados bancários e até o endereço IP. Se a sua empresa mantém cadastro de clientes, contrata empregados, atende por WhatsApp, usa câmeras ou tem um site com formulário, ela trata dados pessoais.

Existem exceções?

Sim, mas são restritas (art. 4º da LGPD): uso particular sem fins econômicos, fins exclusivamente jornalísticos, artísticos ou acadêmicos e atividades de segurança pública, entre outras. Atividades empresariais, em regra, estão dentro da lei.

E as pequenas empresas?

A Autoridade Nacional de Proteção de Dados (ANPD) criou regras simplificadas para agentes de tratamento de pequeno porte (Resolução CD/ANPD nº 2/2022), que flexibilizam algumas obrigações. Isso não isenta o negócio de cumprir a lei.

O que significa “se adequar”

  • Mapear quais dados são tratados, para qual finalidade e com quem são compartilhados.
  • Definir a base legal adequada para cada tratamento.
  • Ter política de privacidade e avisos claros para os titulares.
  • Adotar medidas de segurança proporcionais ao risco.
  • Ter um canal para atender solicitações dos titulares.
  • Ajustar contratos com fornecedores que acessam dados.
